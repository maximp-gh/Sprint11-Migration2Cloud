# Модель TCO: ключевые допущения

* Составлено с использованием экономических и стоимостных данных, предоставленных системой ИИ "Алиса".
* Горизонт: 36 месяцев.
* Валюта: рубли (для наглядности).
* Курс: условно 90 ₽ за условную единицу, где применимо.
* FTE аналитика: 250 000 ₽/мес (среднерыночная ставка в РФ для опытного аналитика данных).
* FTE инженера данных / DevOps: 300 000 ₽/мес.
* Для Yandex Cloud взяты ориентиры по on‑demand тарифам (не Reserved/Savings Plan) для консервативной оценки.
* В текущей архитектуре учтены «скрытые» затраты: ручной труд аналитиков, простои из‑за устаревших компонентов, риски комплаенса.

# Текущая архитектура (Legacy)

Компоненты:

* DWH: Microsoft SQL Server 2008 (on‑prem или IaaS).
* Power BI (лицензии + хостинг отчётов).
* Power Builder (поддержка легаси‑приложений).
* ESB: Apache Camel.
* ИИ‑сервисы: Python.
* Финтех‑сервисы: Golang и Java.

# Целевая архитектура (Yandex Cloud)

Компоненты:

* Kafka (потоки событий).
* Nessie (Git‑like управление версиями таблиц).
* Object Store (S3‑compatible для сырых данных).
* DataHub (метаданные, lineage, теги).
* Airflow (оркестрация ETL/ELT).
* Dremio (витрины, семантический слой, ускорение запросов).
* Kubernetes (контейнеризация сервисов).

Ключевые драйверы экономии

1. Снижение ручного труда аналитиков. В целевой архитектуре Dremio и DataHub дают семантический слой и поиск по метаданным: аналитик быстрее находит нужные данные и витрины, меньше времени тратит на выгрузки и согласования.
2. Автоматизация ETL/ELT. Airflow + Kafka позволяют строить воспроизводимые пайплайны, снижая долю «ручных» интеграций и ошибок.
3. Оптимизация хранения. Object Store + Nessie дают дешёвое хранение «сырых» данных и контроль версий таблиц без дублирования.
4. Динамическое масштабирование. Гибкость лицензий и инфраструктуры. В облаке  оплачивается фактическое потребление, а не фиксированные лицензии и железо.
5. Снижение рисков. Централизованные механизмы безопасности (KMS/Vault), аудит и классификация уменьшают вероятность штрафов и репутационных потерь.
6. Менее затратное и длительное подключение новых сервисов. Развитие бизнеса.
